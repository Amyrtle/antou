# 案头 antou · 作品介绍

> v0.3.1 ｜ 桌面式研究工作台 ｜ 读 → 写 → 发

## 一句话

给做实验、写综述的研究生用的工作台：**论文拖进来直接问，答案带原文引用；答案里的数值一键变成数据表和报表；报表快照直接发成邮件。** 中间不切网页、不换工具。

## 为什么做

研究生的日常是三个断开的动作：在 PDF 阅读器里读，在 Excel 里整理，在邮箱里汇报。三处之间靠复制粘贴和记忆连接，**最容易丢的是「这个数字是从哪篇论文的哪一段来的」**。做完一张表，过两周自己都说不清来源。

案头把这三件事摆成三条纵向轨道，链路就是版式本身：

```
读（文献问答 + 证据栏） → 写（数据表 + 报表） → 发（邮件 + 快照附件）
```

不是三个 tab，也不是三个页面。屏幕从左到右就是工作顺序。

## 三条轨道各做什么

**读**｜PDF 拖到页面任意位置即入库（pdf.js 本地解析，不上传）。提问范围可选「全部文献 / 勾选的 N 篇 / 某个标签」。回答把 **「原文摘录」和「模型推断」分成两种样式**——这是刻意的：摘录来自检索命中的原文片段，推断是模型归纳的，两者混在一起就等于让读者替模型背锅。点回答里的角标，右侧证据栏滚到那一段并高亮，显示页码与相似度。

**写**｜点「带着答案去建表」，答案里的数值落成一张可编辑的表：单元格可改、行列可增删、列类型可切、首列冻结、列头三角出统计浮层（均值/中位数/极值/直方图）。表格与报表双视图，报表给三张指标卡加一张图——指标名是中文长句时自动换成横向条形，名字排左侧，不挤在横轴上。导出 CSV / XLSX / PDF，多表可合成多 sheet。

**发**｜收件人 chip、三套模板（周报 / 数据核对 / 投稿催稿）、变量 chip 未填标橙、报表快照当附件卡、发送前三项检查（收件人 / 变量 / 附件）全绿才放开「发送」。发送记录可回看，可导出 `.eml`。默认是**本地模拟发送**，界面如实标注「不经过外部服务」；填了 EmailJS 三参数才真发。

## 轨道之间是通的

- 「读」里点「带着答案去建表」→ 右轨立刻切到那张新表，问答窗吸左半、表窗吸右半，并排对照。
- 「写」里导出时勾「导出后邮件发送」→ 右轨立刻切到新草稿，附件卡已挂上、变量已按表填好。
- 每条轨道右上角「拖出」可变成独立浮动窗口，能拖、能吸边、能双击铺满；轨道位置留「收回」入口。

## 零配置

打开就有内容：3 篇示例论文（带页码与段落坐标）、1 张示例表、1 个问答线程、1 封填好变量的草稿。**不申请任何 key、不发任何请求也能完整演示一遍**。数据全在本机：论文正文与分块在 IndexedDB，表 / 草稿 / 设置在本机存储。

## 技术

Vite 5 + React 18 + TypeScript + Tailwind + Zustand；pdf.js（文本层解析）、minisearch（BM25 检索）、SheetJS（XLSX）、ECharts（懒加载）。纯前端单页应用，没有后端；`serve.py` 只做 SPA 回退与禁缓存，双击 `启动.bat` 即可。

## AI 使用说明（哪些地方真的用了 AI）

### 一、产品运行时

| 位置 | 用没用 | 说明 |
|---|---|---|
| 文献检索 | **不用大模型** | minisearch 的 BM25 关键词检索，本地跑，零延迟、零成本 |
| 问答生成 | **可选** | 设置里填 DashScope key 后，把检索命中的片段交给 `qwen-plus`，要求按 JSON 返回「摘录 / 推断」两类段落；不填 key 时走本地归纳（把命中片段组织成回答），界面明确标注当前是「在线模型」还是「本地检索」 |
| 思考强度 | 有 | 四档 off / low / medium / high，联动超时、上下文预算与跨厂商参数映射（见 `docs/MODEL_PARAMS.md`） |
| 数值抽取 | **不用** | 正则 + 单位清洗，抽不出来就是抽不出来，不猜 |
| 报表 / 导出 / 邮件 | **不用** | 全是确定性计算与模板渲染 |

刻意没做的：没有向量库（P1 计划），没有把 PDF 上传到任何服务器，没有让模型自由生成数字。回答里的每个角标都能点回原文，就是为了防止「看起来像引用」。

**边界要说清**：目前「摘录」取自检索命中的原文片段，**尚未做二次校验**（模型给的 quote 是否真在原文里，属于待办 P1）。所以样式上区分了摘录与推断，但没有做到「校验失败的摘录自动降级」。

### 二、开发过程

这个项目的代码、自测脚本、部署排错，是在 AI 编程助手（Qoder / WorkBuddy）配合下完成的；需求、验收、判断由人做。本次 v0.3.1 的 7 处修复就是完整的一轮：AI 读代码 → 写探针复现 → 改 → 用 `scripts/check-table.mjs` 与 `scripts/e2e.mjs` 验证 → 出修复记录。

### 三、这份材料

演示视频是用脚本驱动无头浏览器录的（Playwright），不是手点录屏；PPT 与文档由 AI 起草、人审。
