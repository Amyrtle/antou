# v0.2 启动问题：查了什么、改了什么

## 先说结论

不是路径锁死，也不是启动慢。我在本机把包解开实测：

- 源码里搜 `D:/`、`C:/`、`file://`、`localhost:5173`，只有 HANDOFF.md 里提到过仓库路径，代码里一处都没有
- 放到 `D:\tmp\有 空格 目录\antou v0.2` 这种带中文带空格的路径下，照样能起
- 从敲下 `python serve.py` 到页面能访问，0.3 秒左右；首屏 1.2 秒
- zip 里没有 `node_modules`，也没有任何 `.bat`

所以「启动有问题」实际是两件事叠在一起：

1. 没有入口脚本，拿包的人只能双击 `index.html`——而 `dist/index.html` 里写的是绝对路径 `/assets/index-*.js`，`file://` 打开必然白屏；或者去跑 `npm run dev`，报 `'vite' 不是内部或外部命令`；或者跑 `npm install`，国内网络下几分钟没动静，看着像卡死。
2. 有一个真 bug：每点一次「带着答案去建表」就多叠一个数据表窗口，而且这个坏状态被写进 localStorage 了，刷新还在。

## 叠窗口那个 bug

`QaWindow.onBuildTable` 里是无条件 `addWindow(...)`。同样的逻辑在 `StageRail`、`CommandPalette`、`caseImport` 各写了一遍「先找同类型窗口，有就换 payload，没有才新建」——四处重复，漏一处就出这个 bug。

改法：在 `store/windows.ts` 加一个 `open(kind, title, opts)`，语义就一句：同类型窗口存在就复用（顺带取消最小化、换 payload、聚焦），不存在才新建。上面四处全改成调它。

顺手把 `Canvas.tsx` 的首屏播种也加了幂等。原来只靠 `useRef` 挡，React 18 StrictMode 下 effect 跑两次挡不住，再加一层 `window.__antouSeeded`。

## 启动方式

Windows 双击 `启动.bat`。它做三件事：找 Python；没有 `dist` 就先构建；起服务并开窗口。找不到 Python 会告诉你去哪装，不会一闪而过。

命令行等价：

```
python serve.py --port 8000 --open
```

`--open` 现在不是弹浏览器标签页，而是用 Edge/Chrome 的 `--app` 模式开一个没有地址栏、没有标签栏、没有书签栏的窗口。找不到 Chromium 内核才退回默认浏览器。另外 8000 被别的程序占着时，会先探一下那个端口上是不是案头：是就直接复用（自己上一次没关干净），不是就换端口并把换到哪打出来。

要改代码才需要 Node：

```
npm install          # 建议先换源：npm config set registry https://registry.npmmirror.com
npm run dev
npm run build
```

## 装上新版后先清一次 localStorage

叠窗口的坏状态已经写进浏览器了。F12 → Console 粘一行：

```js
localStorage.removeItem('antou.windows'); location.reload()
```

只想清窗口就删这一条，数据表和邮件草稿留着。要彻底重来再 `localStorage.clear()`。

## 界面

上一版是暖米色纸底 + 宋体标题 + SVG 噪点纹理 + 指针聚光，那套配色和质感偏「复古排版」。这一版整个重做：

**布局**：原来是「顶栏 + 左侧阶段收件箱 + 中间浮动窗口桌面 + 底部状态栏」。问题是左栏的阶段 tabs 和中间的窗口是两套互不同步的逻辑，同一条信息（左栏 tab 的数量、状态栏的数量、窗口标题的数量）在屏幕上说了三遍，而「读 → 写 → 发」这条链路——产品唯一的主张——完全没体现在版式上。

改成三条纵向轨道，比例 45 / 29 / 26，**链路就是版式**：

```
读 3 篇文献  →│ 写 1 张表    →│ 发 1 封
```

轨道之间那道分界线上骑一个圆形箭头徽标。原来的左栏和底部状态栏整个删掉——文献列表、数据表列表、草稿列表收进各自轨道头部的切换器。

轨道之间是真的通的：读轨道点「带着答案去建表」，写轨道立刻切到那张新表；写轨道导出并勾「导出后邮件发送」，发轨道立刻切到那封新草稿。不再开新窗口，也就不会互相遮挡。

**视觉**：字体全站走系统 UI 字体（Segoe UI / 微软雅黑），标题不再用衬线；底色中性冷灰 `#e8ebf0`，内容区纯白，标题栏和工具栏用 `#f5f6f9` 分层；强调色统一成一个系统蓝 `#0a63c9`，深绿和暖金都去掉了；窗口圆角 12→8，按钮圆角 6→4，标题栏 34→30；删掉噪点纹理、指针聚光、状态栏走马灯、按钮 hover 上浮这些网页动效；设置面板从「占满整屏但内容很少」的抽屉改成居中的首选项对话框，左边竖排 tab。

原来那个色块 + 单字「案」+ 版本号的 logo 去掉了，顶栏只留字标和一句「读文献 · 写数据 · 发邮件」。

顺手修的几个显示问题：报表图表的类目名原来在生成报表时就被截断成 6 个字，导致 `5-way 1-shot` 和 `5-way 5-shot` 变成同一个标签——改成存全名、渲染时再截；摘要表补了表头、数字列不换行；命令面板的快捷键提示原来写死成 `⌘1`，Windows 上不对，改成按平台显示 `Ctrl+1`。

## 还没做的

- 如果 `dist/index.html` 被直接双击，现在会显示一页说明（告诉你去点 `启动.bat`），但页面本身仍然打不开——ES module 在 `file://` 下被浏览器拦，这个没法绕，除非改成单文件 IIFE 打包
- 坏掉的 localStorage 不会自动迁移，只能手动删那一条
