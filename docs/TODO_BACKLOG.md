## E. 已知问题（非任务，是要盯的坑）

- [ ] Tailwind 颜色用 CSS 变量时**不能写** `bg-accent/40` 这类透明度修饰，会整体失效，需要 rgba 走 inline style
- [ ] `table-fixed` + `colgroup` 的百分比必须加总 100%，否则列名被截成一个字
- [ ] 数值抽取的指标名靠正则清洗，仍有噪声（如"策略组合取得"）；正解是用模型抽取
- [ ] 在线模型失败会**静默降级**到本地检索（回答下方有黄条提示），建议补"重试"按钮
- [ ] 邮件发送失败会保留草稿并显示原因，可重试（这条已实现，别改坏）
- [ ] PDF 走 pdf.js 文本层，扫描件无内容时必须在列表里明确标"失败/无文本层"，不能假装成功
